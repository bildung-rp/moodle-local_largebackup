\# Large Backup Upload Plugin



Ermöglicht das Hochladen von MBZ-Dateien >256MB.



\## Installation

1\. Plugin nach `moodle/local/largebackup/` kopieren

2\. Als Admin einloggen

3\. Moodle erkennt das Plugin automatisch



\## Nutzung

\- Als Trainer in einen Kurs gehen

\- Im Kurs-Menü: "Große Sicherung hochladen"

\- MBZ-Datei auswählen und hochladen

\- Wählen: Neuer Kurs oder Import
